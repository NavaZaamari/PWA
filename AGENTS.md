## What Lovable manages

Rules outside this block are the project's own. Change the pieces below in
Lovable, not by hand. With the [Lovable MCP](https://mcp.lovable.dev)
connected, `send_message` asks Lovable to do it; otherwise ask the user to
use the editor.

- **Database.** Do not add or edit `supabase/migrations/` or `drizzle/`.
  Ask Lovable to change the schema.
- **Generated files.** Do not edit a file whose header says it is automatically
  generated.
- **AI gateway.** Keep model calls on Lovable's gateway, and keep
  `LOVABLE_API_KEY` out of browser code.
- **Connectors.** Lovable provides native connectors. `list_connectors` shows
  which are enabled; `add_connector` only returns the dashboard link. When a
  connector is enabled, calls go through the connector gateway and need
  `LOVABLE_API_KEY`. When Lovable does not provide one, users can bring their
  own key and store it in Secrets.
- **Secrets.** Lovable manages them. Do not put secret values in the repo.

## Architecture rules
- Screens read/write data only through `src/hooks/api.ts` (TanStack Query) → `src/lib/api` repository interfaces; `src/lib/api/mock` is the localStorage implementation. Why: a real backend replaces the mock without touching UI.
- Routes render client-only (`defaultSsr: false` in `src/start.ts`). Why: all data and the session live in browser localStorage.
- Each signed-in page is its own route file with `beforeLoad: requireAuth` and wraps its content in `AppShell` (no pathless layout). Why: keeps `/` owned by `src/routes/index.tsx`.
- All UI copy lives in `src/i18n/fa.ts`; use logical Tailwind utilities (ms/me/ps/pe/start/end) and `<bdi dir="ltr">` for Latin text. Why: RTL-first, i18n-ready.
- No remote URLs for fonts/assets/scripts; fonts come from `@fontsource-variable/*`. Why: app must work in Iran without a VPN.
- Service worker is generated by vite-plugin-pwa and registered only from `src/components/pwa/register-sw.ts` (guarded off in dev/preview/iframes); the manifest is hand-written in `public/manifest.webmanifest`. Why: stale workers must never hit the editor preview.
- Business rules are covered in `src/test/rules.test.ts`; update it when a rule changes.
